# Terroir: revised visual options

These are concept studies, not implemented screens. All generated bottles and inventory values are illustrative. Exact wine photography remains subject to the prototype's existing identity and provenance requirements.

## A — The Cellar Index

Primary: Fidèle Editions, retrieved through Refero MCP (d8496f36-c811-443f-8590-926532d5de7a). Preserve paper #f8f7ef, blue #1664eb for brand/links/active states, black #121212 primary buttons, sharp geometry and open rows. Borrow Shopify's distinct quantity and location fields and Uber Eats' image-assisted identification. The user's floor-use requirement gives priority to wine identity, stock, bin and a reachable pour action. No decorative gradients or dense metadata grids.

## B — The Wine Atelier

Primary: Aesop reference titled NGLORA in Refero (58407c0f-2290-46d4-9d54-08d9ca5deeac). Preserve parchment #fffef2, charcoal #333333, square controls, no shadows, and frontal isolated bottle photography. Humanist headline only for page titles; Swiss sans-serif for operational text. Borrow Uber Eats' visual product selection and Shopify's explicit save/action structure. This direction depends on complete, verified bottle imagery in the real product; generated concept bottles must not enter the inventory database.

## C — The Service Desk

Primary: Dot Inc. (be0ee9e8-1c10-4688-b154-9f18766a1ef4). Preserve white/cloud-gray surfaces, black text, geometric sans-serif, 20px cards, 8px buttons, and orange #ff5a2f primary action backgrounds. Use black button text for contrast. Borrow Shopify's focused edit workflow and large quantity control. Task-first entry and visible exceptions follow the user's restaurant/mobile brief. Sequential reconciliation is a proposed interaction, not a claim that it already exists.

## Shared rules and review

- Same restaurant use case; genuinely different hierarchy and composition.
- 44px minimum touch targets; readable names and vintages; 17px mobile inputs in implementation.
- Quantity fractions refer to full bottle capacity: for 750ml, quarter 188ml, half375ml, three quarters563ml, full750ml (rounded as existing implementation).
- Preserve authentication, tenancy, import confirmation, reconciliation safeguards and image provenance.
- Review concepts for visual direction. Recheck exact text, math, control sizes and actual behavior in code.
